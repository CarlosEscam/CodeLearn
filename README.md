# CodeLearn

Diseño de una **plataforma de e-learning centralizada** para facilitar la creación, gestión y realización de cursos digitales.

Proyecto de la asignatura *Desarrollo orientado a plataformas*, Universidad de Pamplona, Centro de Estudios de Villa del Rosario, 2025.

**Autores:** Carlos Alberto Escamilla Mariño, Kevin Andrés Rojas Marín y Jonathan David Cedeño Rodríguez.
